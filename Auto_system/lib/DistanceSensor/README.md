# DistanceSensor Library

## 文件夹作用
专为 **GP2Y0E03** 距离传感器编写的驱动库。支持 I2C 通信和模拟电压输出两种读取方式。

## 主要函数
- `begin()`: 初始化传感器，设置使能引脚，并配置 12位 ADC 分辨率。
- `readDistanceI2C()`: 通过 I2C 总线读取精准距离（单位: cm）。
- `readVoltage()`: 读取模拟输出的电压值（V）。
- `wakeUp()`: 强制唤醒传感器。

## 注意事项
- 传感器 I2C 地址默认为 `0x40`。
- 接线时请确保使能引脚（GPIO1）连接正确。
