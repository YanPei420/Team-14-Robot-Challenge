# Arduino Giga 巡线避障小车项目

本项目是一个基于 Arduino Giga R1 开发板的智能小车控制系统。它集成了 WiFi 控制、UDP 通信、红外传感器（IR）、激光雷达（Lidar）、电机驱动和舵机控制等功能，旨在实现一个模块化、易于扩展的巡线与避障系统。

## 项目目录结构说明

为了保证代码的可维护性和模块化，本项目采用了清晰的文件夹结构。以下是各文件夹的详细说明：

### 1. `include/` - 头文件目录
该目录存放全局性的定义和配置文件，不包含具体的逻辑实现。
- **`config.h`**：**【核心文件】** 集中管理全车所有的引脚定义（如 `PIN_SERVO`, `PIN_IR_SENSOR`）和全局参数（如避障阈值、默认电机速度）。
- **`arduino_secrets.h`**：存放敏感信息，如 WiFi 的 SSID 和密码。
- **`wifi_handler.h`**：WiFi 模块相关的函数声明。

### 2. `lib/` - 自定义模块库目录
这是项目的核心模块化部分。每个硬件模块都被封装成了一个独立的库，包含 `.h` 和 `.cpp` 文件。
- **`IRSensor/`**：封装了红外传感器的读取逻辑。
- **`LidarSensor/`**：封装了激光雷达的通信和测距逻辑（预留接口）。
- **`MotorControl/`**：封装了 Motoron 电机驱动器的控制逻辑，提供前进、停止、调速等接口。
- **`ServoControl/`**：封装了舵机控制逻辑，用于控制避障云台或转向。

### 3. `src/` - 源代码目录
存放项目的主逻辑和实现。
- **`main.cpp`**：主程序入口。负责初始化所有模块（`setup()`）和执行避障/控制算法（`loop()`）。
- **`wifi_handler.cpp`**：WiFi 联网和 UDP 协议处理的具体实现。

### 4. `test/` - 测试目录
存放用于测试硬件或特定算法的脚本，例如 `test.cpp` 可用于测试 WiFi 连通性。

### 5. `.pio/` & `.vscode/` - 工具配置目录
- **`.pio/`**：由 PlatformIO 自动生成的编译中间文件和构建结果，通常不需要手动修改。
- **`.vscode/`**：包含 VS Code 的项目设置，如 C++ 智能感知配置和任务定义。

### 6. `platformio.ini` - 配置文件
PlatformIO 的核心配置文件，定义了开发板型号（Giga R1）、依赖库（如 `pololu/Motoron`）以及编译选项。

## 如何使用

1. **修改引脚定义**：
   如果你的硬件连接有所改变，只需打开 `include/config.h` 修改对应的 `PIN_` 常量即可，无需改动其他代码。

2. **配置 WiFi**：
   在 `include/arduino_secrets.h` 中填入你的 WiFi 账号和密码。

3. **编译与上传**：
   使用 VS Code 的 PlatformIO 插件，点击底部的“对勾”图标编译，点击“右箭头”图标上传到 Arduino Giga 开发板。

4. **串口监控**：
   打开 PlatformIO 的 Serial Monitor（波特率 115200）查看系统运行状态和测距调试信息。

## 硬件要求
- **主控**：Arduino Giga R1 WiFi
- **电机驱动**：Pololu Motoron 系列驱动器
- **传感器**：红外避障传感器、激光雷达（可选）、舵机云台
